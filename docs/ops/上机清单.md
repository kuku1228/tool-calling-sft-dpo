## 1. ✅ 基线（已完成）

```bash
python -u scripts/eval/run_baseline.py --label baseline  --num-samples 4
```

**实测结果**：106 任务，单次准确率 **38.9%**，pass@4 **43.4%**，pass^4 **34.0%**。

按类别：`weather_advisory 90.0%`、`baggage 67.9%`、`cancellation 62.5%`、`error_correction 55.0%`、
**`flight_search 0.0%`、`booking_flow 0.0%`、`multi_tool 0.0%`、`multi_turn 12.5%`**。

> 那三个 0% 是**未训练基座模型的能力问题**，不是语料缺口（实测语料对 52 个机场码 52/52 全覆盖、
> 观测轮任务 36 个、multi_tool 任务 12 个）。SFT 应能显著拉起这三类。

取数（键名已核实：数字在 `headline` 下，是 `pass_at_k` / `pass_hat_k`）：

```bash
python -c "
import json
r=json.load(open('experiments/baseline/eval_report.json'))
h=r['headline']
print('任务数=%d  准确率=%.1f%%  pass@%d=%.1f%%  pass^%d=%.1f%%' % (
    r['num_tasks'], h['accuracy']*100, r['primary_k'], h['pass_at_k']*100,
    r['primary_k'], h['pass_hat_k']*100))
for c,v in sorted(r['by_category'].items(), key=lambda x:x[1]['accuracy']):
    print('  %-20s %6.1f%%  (n=%d)' % (c, v['accuracy']*100, v['num_tasks']))
"
```

## 5. 已知问题与规避（不影响跑通）

| 问题 | 症状 | 规避 |
|---|---|---|
| **`analyze_errors.py` 写死 v1 任务集** | 「样本数 N / 成功 0 / 错误类别为空」 | 本地已修（新增 `--task-set`），**修复版尚未上传**。云端暂时跳过此步，或用 `eval_report.json` 的 `by_category` 代替 |
| **matplotlib 无中文字体** | 大量 `Glyph … missing from font(s) DejaVu Sans` | 只影响图片文字，数据无影响。要修：`apt-get install -y fonts-wqy-zenhei && rm -rf ~/.cache/matplotlib` |
| `dpo_recovery` 切片覆盖不足 | 缺 40/52 机场码、缺 `cancel_booking`、观测行为 0 行 | 解读该实验时**不要用它的总体准确率**论证整体能力（详见 `docs/ablation/ablation_report.md` §8.7） |
| `multi_turn` 无训练样本 | 语料 0 个「跨轮改主意」任务，评测有 6 题 | 该类别提升有限属预期，报告中说明 |
| `dose000/030/100` 旧文件（60 行） | 测试报「切片缺全部工具」 | 已修（测试改为数据驱动豁免）；若仍报错，删除 `data/preferences/dose*.train.jsonl` 后由 `python scripts/train/dpo_dose_response.py --prepare-only` 重新生成（正确版为各 1000 对） |
